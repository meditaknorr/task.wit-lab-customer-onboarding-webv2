Steps to run the project:

1... install on your machine `node v12.22.12` (I have used `nvm` to be able to install more than 1 node versions);
2..., on the root of the project, run on your terminal the command `yarn` if you use yarn or use `npm install`;
3..., jump out from `develop` branch and run into `DEMO` using the git command `git checkout DEMO`;
4..., while on `DEMO` branch and yet on the root of the project;
5..., if you have done all ok on the recommended steps above, then you just need to run the command `yarn start` or `npm start`
6..., then on your browser access [http://localhost:3000](http://localhost:3000) and use the command Ctrl + Shift + J and toggle device emulation to see the page as mobile
